# grokbot-hyperframes-skills
用 HTML 写视频（HyperFrames）的环境准备与使用规范。**全部能力来自上游** [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)（Apache-2.0）及其官方技能，本仓库不复制上游技能内容，只提供：
- `scripts/setup.sh`：检查 Node / ffmpeg 并通过 npx 拉起官方 CLI
- `SKILL.md`：给 AI 助手的使用流程

## 上游致谢
- heygen-com/hyperframes — Apache-2.0
- GSAP、Anime.js、Lottie、Three.js 等动画库按各自许可证

## 中文项目说明

为使用 HTML 编写视频的 HyperFrames 提供环境准备脚本与 AI 使用流程。视频制作能力来自 heygen-com/hyperframes 及其官方技能，本仓库仅提供轻量适配。

**使用入口：** 从 `scripts/setup.sh` 的 Node、ffmpeg 检查和官方 CLI 启动入口开始，工作流程见 `SKILL.md`。

<a id="project-overview-en"></a>
## English project overview

Provides environment preparation and an AI workflow for creating HTML-based videos with HyperFrames. Video capabilities come from heygen-com/hyperframes and its official skills; this repository is a lightweight adapter.

**Getting started:** Start with `scripts/setup.sh` for Node and ffmpeg checks and the official CLI entry point; see `SKILL.md` for the workflow.

**Scope:** Does not copy upstream skill content. HyperFrames and the animation libraries retain their respective licenses.
